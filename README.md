# 码上有解商家工作台原型

本地运行的无依赖网页原型，包含经营总览、注意力矩阵、统一收件箱和订单管理。页面中的客户、消息、订单和营销数据全部是模拟数据；目前没有连接平台账号或后端服务。

推送到 GitHub `main` 分支后，`.github/workflows/deploy-pages.yml` 会发布静态站点。仓库的 Pages 来源需要设为 **GitHub Actions**。

## 运行

在此目录启动静态服务器：

```powershell
py -m http.server 4173
```

浏览器打开 `http://localhost:4173`。也可以直接打开 `index.html`。

## 原型行为

- 收件箱支持平台筛选、未读筛选、搜索、会话查看、跟进状态切换和本地演示回复。
- 订单管理支持订单号/客户/服务搜索、平台与状态筛选、演示清单 CSV 导出。
- 注意力矩阵按平台和内容主题展示模拟互动、咨询和订单数量；右侧线索从矩阵数据计算。
- 可录入近 7 天的平台、内容主题、互动、咨询和订单汇总，矩阵与总览会即时更新。
- 演示回复只存在当前页面内存中，不会发送到平台或长期保存。
- 手工录入的营销数据目前也只在当前页面内存中；刷新后会重置。

## 后续接入边界

每个平台的授权、数据同步和可用操作都要独立核实；接入时保留平台来源、内容主题、统计口径和更新时间。注意力分析只使用有明确来源的数据，无法从接口取得的内容指标需要手动导入或标为未知，不能按零值处理。
